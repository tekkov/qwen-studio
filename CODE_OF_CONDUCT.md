# Code of Conduct 🤝

Qwen Studio is a community for curious, practical, and kind people building useful local-first AI tools.

We expect participants to:

- Be respectful, patient, and constructive.
- Assume good intent while staying precise about impact.
- Welcome beginners and explain jargon when it matters.
- Focus criticism on ideas, code, and behavior — never on people.
- Keep private data, credentials, and unsafe demonstrations out of public issues.

Harassment, discrimination, doxxing, threats, spam, and deliberate disruption are not welcome. Maintainers may edit, remove, or close content that violates this code and may block participation when necessary.

For sensitive concerns, contact the maintainers privately through GitHub rather than opening a public issue.
